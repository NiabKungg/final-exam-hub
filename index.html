Operating Systems สอบคำนวณหนัก

สอบถูก/ผิด (ตอบผิด −1!) + เติมคำ + โจทย์คำนวณเยอะกว่า Midterm
เน้น Final: Paging, Page Replacement, CPU Scheduling, ไล่ fork(), Semaphore, Deadlock, Banker's, File System

  • ไล่โค้ด fork() ทีละบรรทัด พร้อม process tree
  • ตาราง Gantt ทุกอัลกอริทึม scheduling
  • คำนวณ Paging แบบที่ "คนส่วนมากไม่ทัน" ให้ทันขึ้น

Data Structures & Algorithms วาด tree ครึ่งข้อสอบ

Short note 1 แผ่น · ออกทฤษฎีเกือบหมด + แลป 1 ข้อ
เน้น Final: Sorting ทีละสเต็ป, Heap/PQ, BST, AVL, Splay, MST (Kruskal), Dijkstra, โปรแกรม Binary String

  • ไล่ sort ทีละ pass พร้อมภาพกล่องตัวเลข
  • วาด AVL rotation / Splay ทีละขั้น
  • โค้ด searchIter / Binary String พร้อมเฉลย

📋 รูปแบบข้อสอบแต่ละวิชา (จากรีวิวรุ่นพี่)

วิชารูปแบบข้อควรรู้จากรุ่นพี่
OS ถูก/ผิด 2 ตัวเลือก (ตอบผิด −1 ถูก +2 ไม่ตอบ 0) + เติมตัวเลข/คำสั้น ๆ ข้อสอบเยอะกว่า Midterm เน้นความเร็ว 3 ชม.แทบไม่พอ · Open Book แต่เสียเวลาถ้าเปิดทุกข้อ ควรจดสรุปสั้น ๆ · โจทย์คำนวณ Paging คนส่วนมากไม่ทัน · ไล่ fork() มีจุดหลอกเยอะ · โค้ดทุกข้อ compile ผ่าน ไม่ต้องตอบ "Error"
DSA เขียนตอบ แสดงขั้นตอน + ผลลัพธ์สุดท้าย · เติมคำ 15 ข้อ (Sort/Search/Big-O) · แลป 1 ข้อ Short note ได้ 1 แผ่น · ครึ่งหนึ่งของข้อสอบคือ "วาด tree" (BST, AVL, Heap, Splay) · ให้ชุดตัวเลขมาไล่ sort/สร้าง tree · อาจมีเขียนโปรแกรมสั้น ๆ เช่น Binary String
DB เขียนตอบ รวม 120 คะแนน 6 ตอน (อาจารย์ประกาศแนวชัด ๆ) วิพากษ์ Data Model 10 · Normalization 40 (1–3NF, BCNF, 4NF, 5NF) · Transaction 30 (Recovery + Concurrency) · DB Concept 10 · Data Warehouse 15 (ไม่ออกออกแบบ) · SQL 15 (Outer JOIN, Subquery, Correlated Subquery)
SE แบบจับคู่ + เขียนตอบ จับคู่ Testing และ Maintenance · เขียนแผนทดสอบ/บำรุงรักษาจากโปรเจกต์ตัวเอง · FR & NFR (CS-Hospital / CS-Pizza) · Use Case Diagram · Schema · สถาปัตยกรรมซอฟต์แวร์
⚠️ กลยุทธ์ข้อถูก/ผิดแบบหักคะแนน (OS) ถูก +2, ผิด −1, ไม่ตอบ 0 → ถ้าไม่รู้จริง ๆให้ ข้าม (คาดหวัง 0 ดีกว่าเสี่ยง) แต่ถ้ากำจัดตัวเลือกผิดได้ 1 ข้อแล้วเหลือ 50/50 คุ้มที่จะเดา เพราะค่าคาดหวัง = ½(2) + ½(−1) = +0.5 ยังเป็นบวก! ระวังเฉพาะข้อที่รู้ว่า "ไม่แน่ใจเลยสักนิด"

🗓️ ลำดับการอ่านที่แนะนำ (ถ้าเวลาน้อย)

เก็บเรื่อง "คำนวณ" ให้ได้ก่อน (ได้คะแนนแน่นอนที่สุด)

จำ "ตารางจับคู่" สำหรับ SE/OS ทฤษฎี
